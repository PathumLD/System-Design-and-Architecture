# System Design & Software Architecture

A structured, chapter-based course covering the principles and practices behind designing, building, and operating reliable software systems.

## What you'll learn

- Software systems and web request fundamentals
- Application, layered, clean, hexagonal, and vertical-slice architectures
- Monoliths, modular monoliths, microservices, and domain-driven design
- Database design, normalization, indexing, transactions, scaling, and high availability
- REST APIs, authentication, authorization, caching, messaging, and background processing
- Distributed systems, resilience, load balancing, scalability, sharding, and global delivery
- Observability, performance engineering, security, secrets management, and safe deployments
- Docker and Kubernetes fundamentals, operations, networking, storage, and security
- Azure architecture, networking, identity, compute, data, messaging, monitoring, and IaC
- Multi-tenant SaaS architecture, production architecture reviews, ADRs, and system design interviews

## Course structure

The course contains **65 Markdown chapters**, progressing from foundational concepts to production architecture:

1. Begin with [Software Systems Fundamentals](./01-Software-Systems-Fundamentals.md).
