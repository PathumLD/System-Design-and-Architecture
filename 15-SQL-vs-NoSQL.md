# Lesson 15 --- SQL vs NoSQL

## PostgreSQL strengths

-   Relational integrity
-   Transactions
-   Complex queries
-   Constraints
-   Mature indexing
-   JSON support when useful

## Other systems

-   MongoDB: document-oriented workloads
-   Redis: low-latency cache/state
-   Cassandra: distributed high-write patterns
-   Graph databases: relationship-centric queries
-   Search engines: text/search-oriented workloads

## Polyglot persistence

Use different databases when their capabilities solve a real
requirement. Each additional data system creates operational,
consistency, backup, and observability costs.
