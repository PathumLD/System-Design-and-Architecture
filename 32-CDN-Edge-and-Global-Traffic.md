# Lesson 32 --- CDN, Edge and Global Traffic

## CDN

Caches appropriate content close to users.

## Edge responsibilities

-   TLS
-   WAF
-   DDoS/bot controls
-   Routing
-   Cache
-   Origin protection

## Global architectures

-   Active/passive
-   Warm standby
-   Active/active

## Important distinction

Traffic failover is not the same as database failover. Global routing is
easy to describe; globally consistent data is much harder.
