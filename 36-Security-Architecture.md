# Lesson 36 --- Security Architecture

## Start with assets and trust boundaries

Use threat modeling such as STRIDE.

## Major areas

-   Authentication
-   Authorization
-   Tenant isolation
-   Input validation
-   SQL injection
-   XSS
-   CSRF
-   CORS
-   SSRF
-   File uploads
-   Webhooks
-   Secrets
-   TLS
-   Encryption
-   Supply chain
-   Admin actions
-   Error/log exposure

## Defense in depth

Use multiple independent controls rather than trusting one layer.

## Principle

Minimize blast radius: least privilege, isolated credentials, network
boundaries, and scoped access.
