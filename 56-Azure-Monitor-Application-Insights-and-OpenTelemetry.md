# Lesson 56 --- Azure Monitor, Application Insights and OpenTelemetry

## Telemetry

-   Logs
-   Metrics
-   Traces

## Application Insights

Provides application-oriented telemetry and query capabilities through
Azure Monitor.

## OTel

Use OpenTelemetry instrumentation and semantic conventions for
portability.

## KQL

Use queries to investigate: - slow requests - failed dependencies -
exceptions - traffic patterns - availability

## Alerting

Create alerts around service-level symptoms and business impact rather
than every low-level metric.
